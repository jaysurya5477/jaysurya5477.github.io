# jaysurya5477.github.io

Personal portfolio of **Jayasurya Lakkoju**, Senior SAP ABAP Consultant.

Live site: https://jaysurya5477.github.io

## Structure

| File | Purpose |
|---|---|
| `index.html` | Page content |
| `style.css` | Light theme styles |
| `script.js` | Animations, typing effect, mobile menu, demo viewer |
| `demos.js` | **List of demos. Edit this to add videos, slides, PDFs, images** |
| `assets/demos/` | Optional: put demo files here and point to them from `demos.js` |
| `assets/photo.jpg` | Profile photo |
| `assets/Jayasurya_Lakkoju_Resume.pdf` | Resume download |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |

Plain HTML, CSS and JavaScript. No build step.

## Updating

Edit `index.html`, commit and push. GitHub Pages republishes within a minute or two.

## Adding a demo

Open `demos.js`, copy one block, change `title`, `desc` and `src` (a Google Drive, YouTube or Slides link, or a file path such as `assets/demos/my-demo.mp4`), then commit and push. Drive files must be shared as "Anyone with the link can view".
